# Buddy Rig (Part 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the approved throwaway spike into a production `lib/widgets/buddy/` component: a code-drawn, deformable, expressive Buddy with 9 moods, 11 one-shot actions, gaze/blink, speech bubble, and reduced-motion support.

**Architecture:** Generated vector path data (traced from `mascot-happy.png`) is subdivided once, then every frame pushed through a deformation field (breath, sway, gulp/water bulge) and drawn by a `CustomPainter`; the face is procedural. A plain `ChangeNotifier` (`BuddyController`) owns time, mood blending, actions, gaze, blink and the bubble text; widgets only render it. No Riverpod inside the rig.

**Tech Stack:** Flutter 3.50.1 (`package:material_ui/material_ui.dart` for UI files, `package:flutter/widgets.dart`/`dart:ui` for painting), flutter_test.

**Spec:** `docs/superpowers/specs/2026-11-22-animated-buddy-design.md` (§5). 1. **Reduced motion** (`MediaQuery.disableAnimations == true`): Buddy must render, blink, change mood, show bubbles — but no sway, hop, shake, jump or bulge travel. Test in Task 6.
2. **Off-screen / disposed**: a Buddy inside a hidden tab (`TickerMode(enabled: false)`) must not keep ticking; disposing mid-action must not throw. Test in Task 6.
3. **Tiny and huge sizes** (48×48 avatar … full screen): layout must not divide by zero or overflow; zero-size constraints render nothing. Test in Task 6.
4. **Rapid repeated actions** (user mashes "Füttern"): `play()` while an action runs must restart cleanly, not stack overrides or leave the face stuck. Test in Task 5.
5. **Long German bubble text** (≥ 80 chars, e.g. „Puh! Dein Streak-Saver hat uns gestern gerettet …"): wraps within max width, no overflow. Test in Task 6.

**Interfaces:**

- Produces:
  ```dart
  class BuddyFrame { // read-only snapshot for the painter
    double t; FacePose face; double blink; Offset gaze; // gaze normalised, |gaze| ≤ 1
    double tx, ty, sx, sy, rot, breath, sway;
    Offset? bulgePoint; double bulgeAmt; bool bulgeIsWater;
    Offset? foodPos; double foodScale; ui.Image? food; double sparkleP; double hearts;
  }
  class BuddyController extends ChangeNotifier {
    BuddyController({BuddyMood mood = BuddyMood.happy, int seed = 42});
    BuddyMood get mood; set mood(BuddyMood value);
    bool reducedMotion; // default false
    void play(BuddyAction action, {ui.Image? food}); // restarts if same/other action running
    BuddyAction? get currentAction;
    void lookAt(Offset imagePoint, {Duration hold = const Duration(milliseconds: 1800)});
    void say(String text, {Duration duration = const Duration(milliseconds: 2800)});
    String? get bubble; // null when nothing to say
    int get bubbleId; // increments per say(), for AnimatedSwitcher keys
    void tick(double dt); // dt seconds, clamped to [0, 0.05]; notifies listeners
    BuddyFrame get frame;
    bool hitTest(Offset imagePoint); // BuddyShapes.hitPath.contains
  }
  ```
